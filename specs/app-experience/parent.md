# App Experience — Knowledge Base

Owner: App Experience
Status: seeded, not yet populated

This is the team's parent spec: the knowledge base every spec owned by
this team is distilled and merged into. Rules carry the `APPEX-` prefix.

## Scope

Information architecture, navigation, and surfaces shared across the app.
This parent spec determines the IA every other team's surfaces live inside.

## Rules

| Rule | Statement | Status | Source |
| --- | --- | --- | --- |
| APPEX-001 | Every feature surface has exactly one canonical location in the app's information architecture. | ⚠️ Unverified | seeded |
| APPEX-002 | A tab is reserved for a persistent top-level destination, never for a transient flow. | ⚠️ Unverified | seeded |
| APPEX-003 | Deep links resolve to the canonical location rather than a duplicate surface. | ⚠️ Unverified | seeded |
