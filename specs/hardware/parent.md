# HW Team — Knowledge Base

Owner: HW Team
Status: seeded, not yet populated

This is the team's parent spec: the knowledge base every spec owned by
this team is distilled and merged into. Rules carry the `HW-` prefix.

## Scope

Hardware features across the camera and sensor lineup, and the software
features surfaced on each device's plugin page.

## Rules

| Rule | Statement | Status | Source |
| --- | --- | --- | --- |
| HW-001 | A device's plugin page shows only features its hardware model actually supports. | ⚠️ Unverified | seeded |
| HW-002 | Hardware capability is resolved from the device model, never from the plan a user holds. | ⚠️ Unverified | seeded |
| HW-003 | A software feature on the plugin page states which hardware generations support it. | ⚠️ Unverified | seeded |
